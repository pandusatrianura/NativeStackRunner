# Security Policy

## Supported Versions

We release patches and security fixes for the latest major version of NativeStackRunner.

| Version | Supported          |
| :---    | :---               |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

The NativeStackRunner maintainers take the security of our software seriously. If you discover a security vulnerability, please follow responsible disclosure guidelines:

1. **Do not open a public issue.** Publicly disclosing a vulnerability puts users at risk.
2. **Submit via GitHub Private Vulnerability Reporting:**  
   Navigate to the [Security Advisories](https://github.com/pandusatrianura/NativeStackRunner/security/advisories) tab of this repository and click **"Report a vulnerability"**.
3. **Include Detailed Information:**
   - Description of the vulnerability and attack vector.
   - Operating system and version of NativeStackRunner tested.
   - Minimal reproduction steps, proof of concept, or `stack.yaml` configuration.

---

## Response Timeline

- **Initial Acknowledgment:** Within 48 hours of receiving the report.
- **Triage & Assessment:** Within 5 business days.
- **Fix & Advisory Release:** We will coordinate with the reporter to publish a patched release and credit the reporter in the advisory.
